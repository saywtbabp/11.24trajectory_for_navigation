数学模型

原求解器固定所有节点位置，以相邻两段共享的内点速度、加速度和 jerk，以及起始 jerk 为变量。它以可行基准控制多边形构造半空间，再将问题化成白化坐标中的最小距离投影。联合版本在同一向量中加入明确授权的二维内点位置，常量已知的节点只出现在仿射常数项。窗口末端的速度、加速度、jerk 为零。滚动窗口从仍有效的旧参考接入时，可以固定整组起始状态到三阶导数。

令 τ = median(T)，自由导数变量储存为 τʳ·p⁽ʳ⁾。位置使用以窗口起点为原点的米制局部坐标。下列式中，q、v、a、j 表示对应端点的物理量。控制点索引从 0 到 7。

B₀ = qᵢ               B₇ = qᵢ₊₁
B₁ = qᵢ + Tvᵢ/7       B₆ = qᵢ₊₁ − Tvᵢ₊₁/7
B₂ = qᵢ + 2Tvᵢ/7 + T²aᵢ/42
B₅ = qᵢ₊₁ − 2Tvᵢ₊₁/7 + T²aᵢ₊₁/42
B₃ = qᵢ + 3Tvᵢ/7 + 3T²aᵢ/42 + T³jᵢ/210
B₄ = qᵢ₊₁ − 3Tvᵢ₊₁/7 + 3T²aᵢ₊₁/42 − T³jᵢ₊₁/210

固定 T 后，每个控制点写成 B = Mz + c。自由航点在相邻段的四个同侧控制点中具有相同的位置系数。两侧使用同一行节点导数变量，由端点差分恢复时达到 C³。代码还重新对控制点求差分并核对求解变量及首尾状态。

设 Δ⁴ 为第四差分，G = _SNAP_GRAM，F = _SNAP_FACTOR，满足 FᵀF = G。每段物理代价为 840²·T⁻⁷·‖FΔ⁴B‖²。将所有 Snap 块与参考偏离块合并成残差 Rz + d，有以下关系。

J = Jₛₙₐₚ + λₚ Σᵢ∈free ‖qᵢ − qᵢ(ref)‖²
H = RᵀR， f = 2Rᵀd， c₀ = dᵀd
J = zᵀHz + fᵀz + c₀
控制点约束 Aₖ Bₖ,ᵢ ≤ bₖ 代入后得到线性约束 Lz ≤ u
航点区域 qₖ ∈ Cₖ₋₁ ∩ Cₖ ∩ Tₖ，另外可加房间侧和用户半空间

RᵀR 是对称半正定矩阵。实现按列缩放 R，并用 SVD 把可识别的满秩目标白化。若未变换即调用 OSQP，则需提交 P = 2H 和 q = f。当前实现使用 z = z* + Wy，白化后提交 P = I、q = 0，并变换每条原始半空间。斜向法线可同时包含 x 与 y。若无约束极小点已可行，则直接验算；其他情形由 OSQP 从一般线性约束求解。求解后按单位法线计算世界坐标的最大残差，接受阈值为 10⁻⁸ m。接近奇异的系统、不可行解、迭代耗尽及未通过独立复核的解均返回诊断。

预期进度样点使用 (1−s)qᵢ + sqᵢ₊₁。长沿墙段的识别基于输入参考方向，墙法向速度惩罚以优化后的端点平均位移为基准。这两个可选项仍然是仿射残差。默认 λₚ = 100 s⁻⁷，0.10 m 的单点位移对应 1 m²/s⁷ 的代价。可用相同窗口的 Snap、位移和动力学变化比较 30、100、300 s⁻⁷。物理积分按 T⁻⁷ 独立报告。

航点权限、走廊与滚动执行

任务角色位置权限
窗口起终点、全局任务终点、下一动作固定后缀固定
推门准备点、门扇中点接触目标、直接穿门关键点固定，接触状态继续由原控制器执行
普通飞行和门前接近的内点导引航点允许在交集内连续移动
绕行入口和出口附近连接点、退离后接入绕行的局部转接点在成为窗口内点且通过原安全几何认证后允许移动
完成安全分离后的释放过渡点允许在相邻走廊内移动，窗口终点仍固定

走廊由当前状态、原局部参考航点和观测门扇构建。原有墙厚、门扇厚度、0.266 m 机体包络半径和 0.045 m 走廊附加余量均参与求解。原参考方向还产生固定横向带。共享位置分别作为前一段 B₇ 和后一段 B₀，同时受两个走廊约束。附加的每轴 0.18 m 信赖盒和房间侧约束限制节点跨越分隔面。参考弦与优化曲线都落在同一段凸走廊内，可以在不穿过其分隔障碍的情况下连续变形。退化交集可求出线段或单点上的解。交集为空返回不可行，由标准回退处理。

每段 8 个控制点接受半空间复查，再调用原有实体几何凸包认证。门叶估计角变化时，对当前段剩余的 Bézier 子段与后续段重新认证。无有效证书的轨迹被撤销。离散采样净空用于评估，运行准入依据凸包认证。

局部调度持有实际连接位置和对应累计时刻，使用原锚点加路线 revision 找到该局部节点。决策层以执行位置判断是否已到达中间航点，A* 节点和原路线始终使用原锚点。旧的几何候选筛选仍参与两个模式。每次延长或回收段时长都使用同一参考航点、位置权限及走廊重新求解。外层复核保守的速度、加速度、jerk、名义旋翼输出余量和几何约束。

联合求解或其外层时间调整失败时，尝试原固定航点 Minimum Snap。再失败时沿用已认证前缀，或使用制动和保持。继续采用旧参考的 joint 接入可达 C³，改用实测边界状态或回退到原方法时按原有位置、速度、加速度接口衔接。新旧轨迹之间的 jerk 连续性因此取决于接入分支。

验证范围与版本

基线源提交为 f4f18e3d05034ddc746a1ea94635203f69b8763e。复制了当时工作区的 run_demo.py 与 README.md 修改。源基线自动工况在 154.05 s 到达终点，配对的 baseline 自动工况复现了这一时间和 114.658 m 路径长度。场景、XML、原求解器、障碍几何、全局 A* 和推力控制的对应实现通过文件哈希核对。

在 Python 3.9.25、NumPy 2.0.2、MuJoCo 3.3.2、OSQP 1.0.4、SciPy 1.13.1 和 Matplotlib 3.9.4 上验证。13 项自动测试覆盖固定航点和可选正则项等价、连续二维移动、斜向半空间和不相交走廊、零宽交集、固定接触准备点、非零起始状态、门扇变化撤销轨迹、病态与迭代耗尽、回退和锚点保留、外层重求及滚动 C³ 接入。

固定时长和固定走廊下，若固定航点解可行且额外移动区域包含参考点，释放位置变量会扩大可行集。因此在相同目标与边界条件下，最优目标至多等于固定位置问题的最优目标。完整闭环会重新分配时间、改变换轨时刻和起始状态，不能由这条性质推导全程 Snap 或实际飞行时间。

Snap 对执行过的分段参考积分。重规划换轨时只积分旧曲线的实际执行前缀。区间积分使用四点 Gauss–Legendre 公式，七次曲线的 Snap 平方在段内为六次。jerk 和参考曲率取 50 ms 采样，跟踪误差依据 MuJoCo 机体真值。曲率只统计速度高于 0.30 m/s 的样本。最小净空使用自由飞行扫描帧与实际墙体和门扇的实体尺寸，碰撞集合则按物理步采样。接触段数含释放与退离时的门接触，因此可与过门接触步数一起解读。

自动交互。joint 快 0.80 s，Snap 上升约 128%，参考 jerk RMS 上升约 11%。D4–D6 的三次退离转绕行安装计划贡献了联合模式约 179 m²/s⁷ 的 Snap，其中三个首段约为 0.59–0.82 s，baseline 对应约 1.01–1.31 s。T⁻⁷ 的时间缩放、起始状态与安装时刻共同影响积分。D4–D6 的绕行出口实际曲率 P95 均下降，入口实际曲率 P95 均上升。最小抽样净空变化约 −0.3 mm。两次实验均发生释放或退离期间的门接触。

全绕行。joint 路径短约 2.53 m，飞行时间增加 9.90 s。执行参考 Snap 下降约 48%，jerk RMS 下降约 39%，参考曲率峰值下降约 52%。跟踪误差 P95 和最小抽样净空改善。该组表现说明平滑性、路径长度和任务时间需要单独评价。

固定时间复算。对实际安装且有位置自由度的 joint 窗口，用相同走廊、时长、起始位置、速度和加速度，复算固定与自由内点两版纯 Snap 加位置正则。两版均自由求起始 jerk，使用默认信赖盒。自动组 12 窗口中 11 个双解成功且目标下降，中位降幅 23.35%。全绕行组 11 个窗口全部双解成功且目标下降，中位降幅 39.42%。自动组另一个窗口的状态已保留在复算文件。该试验检查内层优化的效果，实际调度仍经过可选正则、房间侧、时间和动态复查。

在线耗时。已在启动时预载 OSQP。单次 QP P95 低于 50 ms 扫描周期，但一个扫描内可能多次试候选和重新分配时长。自动和全绕行 joint 的最大窗口求解时间分别为 135.78 ms 与 78.32 ms，不能视为硬实时达标。求解成功率包含无需进入 OSQP 迭代的无约束极小点可行分支。原有 35 ms 可选候选比较预算按墙钟计时，机器负载可能改变搜索深度。

尚待工程验证。当前实验使用同一地图与一个种子。门角变化直接使旧轨迹失效的行为由自动测试触发，本次飞行只观测到门角更新后的重认证。单种子结果不足以估计跟踪净空、接触频数或时延的分布。下一步可在多种子下按动作统计，并单独检查退离后首段的时间分配与运动连续性。
